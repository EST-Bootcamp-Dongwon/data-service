### U3 결정 — 색 · 타이포 · 차트 스타일 (2026-08-01)

`dataviz` 스킬의 절차대로 정하고 **검증기를 실제로 돌려** 확정했다. 정의는 `static/assets/app.css` 상단에 있다.

| 역할 | 값 | 비고 |
|---|---|---|
| 범주형 8슬롯 | `--c1`~`--c8` (파랑·주황·아쿠아·노랑·마젠타·초록·보라·빨강) | **순서 고정**. 돌려쓰지 않는다. 9번째는 '기타'로 접는다 |
| 시퀀셜 램프 | `--s1`~`--s7` (파랑 한 색상, 연함→진함) | 크기(magnitude)·순서형 전용. 순서형은 `s3` 부터 시작 |
| 다이버징 | `--up`(빨강) ↔ `--down`(파랑), 중립 `--flat` 회색 | 국내 증시 관행. 언제나 부호·화살표와 함께 낸다 |
| 상태(예약색) | `--st-good` · `--st-warning` · `--st-serious` · `--st-critical` | 계열 색으로 재사용 금지. **글자색으로도 쓰지 않는다** |
| 차트 크롬 | `--grid`(1px 실선) · `--axis` · `--ink-muted` | 점선 격자 폐지 |
| 타이포 | 시스템 sans 유지 · `--t-xs`~`--t-3xl` 7단계 | 큰 숫자는 비례폭, 표·축만 `tabular-nums` |

검증 결과 (표면: 라이트 `#ffffff` · 다크 `#1f2226`)

```
라이트  명도대역 PASS · 채도하한 PASS · CVD 최악 인접쌍 ΔE 9.1 PASS · 정상시야 ΔE 19.6 PASS
        대비 WARN — 아쿠아 2.82 · 노랑 2.17 · 마젠타 2.69 → 완화 규칙(범례 + 직접 라벨) 적용
다크    5개 검사 전부 PASS (대비 포함)
```

지켜야 할 규칙 (어기면 색 체계가 무너진다)

- 색은 **순위가 아니라 항목**을 따라간다. 정렬·필터로 순서가 바뀌어도 다시 칠하지 않는다
- Y축 두 개(이중축) 금지. 단위가 다르면 차트를 나누거나 100 기준으로 지수화한다
- 글자는 잉크 토큰을 쓴다. 계열 색을 글자에 칠하지 않는다 (옆의 점·선이 정체성을 맡는다)
- 상태색은 **아이콘 + 글자**와 함께 낸다. 색만으로 뜻을 전하지 않는다

### U6 결정 — `/users` · `/tetris` 이관 (2026-08-01)

**둘 다 앱 메뉴에서 내리고 수업 자료로 남긴다.** 다만 강사님 원본(`lecture/`)은 서브모듈이라
거기에 내 파일을 넣으면 **다음 `git pull` 때 충돌한다.** 그래서 저장소 루트에 별도 폴더를 만들었다.

| 구분 | 위치 | 성격 |
|---|---|---|
| 강사님 원본 | `lecture/` (서브모듈 → `edumgt/api-test2`) | 읽기 전용 · pull 만 |
| **내 실습 아카이브** | **`실습/`** (일반 폴더 · `/practice/` 로 서빙) | M1 이전 화면 8종 원본을 얼려 둠 |
| 현재 작업본 | `app/` · `static/` | 계속 개발 |

- 리팩토링으로 화면 구조를 전면 교체하므로 **8화면 원본 전부**를 아카이브에 넣었다.
  그중 `/stock`·`/yf`·`/krx`·`/kosis`·`/quant`·랜딩은 새 셸로 이식해 앱에도 계속 살아 있고,
  `/users`·`/tetris` 만 앱에서 내렸다.
- 예전 주소(`/users`·`/tetris`)는 **302 로 아카이브에 넘긴다** (영구 이동 301 이 아니라 임시 302 —
  브라우저가 캐시해 버리면 나중에 되살릴 때 사용자 쪽에서 막힌다).
- **사용자 CRUD API(`/api/users`) 는 그대로 살아 있다.** 화면만 옮긴 것이다.
