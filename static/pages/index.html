데이터가 흐르는 방향

아래 계층은 위 계층을 import 하지 않는다. 이 방향만 지키면 순환 import가 생기지 않는다.

  KRX OpenAPI            KOSIS OpenAPI          야후 파이낸스
        │                       │                      │
  app/clients/            app/clients/           app/clients/     ← 외부 연동 (HTTP 호출 · 응답 정규화)
   krx_data.py            kosis_data.py           yf_data.py ──┐
        │                       │                      │       │
  app/repositories/              │                      │       │  ← 저장소 (SQLite 캐시)
   krx_store.py                  │                      │       │
        │                       │                      │       │
  app/services/                  │                      │       │  ← 서비스 (스크리닝 · 투자선 · 팩터)
   market_data.py                │                      │       │
        │                       │                      │       │
  app/routers/            app/routers/           app/routers/      │  ← 컨트롤러 (DTO · 엔드포인트)
   krx_router.py          kosis_router.py         yf_router.py  │
        │                       │                      │       │
  static/pages/           static/pages/          static/pages/     scripts/  ← 화면 · 스크립트
   krx.html · quant.html   kosis.html              yf.html         yf.py (matplotlib)
