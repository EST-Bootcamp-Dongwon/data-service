국내 투자 정보를 한 곳에

흩어져 있는 국내 투자 정보를 모아 두는 수집·보관·조회 서비스다. 시세·통계는 정형 API 로, 공시·뉴스·커뮤니티는 수집으로 모으고, 기업과 산업을 축으로 되찾는다.

무엇을 모으나 — 여섯 갈래

착수 순서는 공시·보고서 → 뉴스 → 커뮤니티·동영상이다. 인증키와 클라이언트가 이미 있고 공공데이터라 이용약관 확인이 필요 없는 쪽부터 한다.
