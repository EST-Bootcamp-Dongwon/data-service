터미널에서 같은 차트 그리기

scripts/yf.py가 이 화면과 같은 app/clients/yf_data.py를 써서 matplotlib으로 그린다. GUI가 없는 환경(WSL·서버)이면 창 대신 data/yf/에 PNG로 저장한다. 

python3 scripts/yf.py                        # 삼성전자(005930.KS)
python3 scripts/yf.py 000660.KS              # 종목 지정
python3 scripts/yf.py 005930                 # 숫자 6자리면 .KS 자동
python3 scripts/yf.py AAPL --save chart.png  # 창 대신 PNG 저장
python3 scripts/yf.py --english              # 한글 폰트가 없을 때
