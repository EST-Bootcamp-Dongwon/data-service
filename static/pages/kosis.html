📊 KOSIS 통계 실험실

국가통계포털 OpenAPI를 검색 → 파라미터 조립 → 호출 3단계로 직접 실험한다. 결과는 ApexCharts로 그린다.

🚀 바로 보기 — 아래를 누르면 1~3단계를 한 번에 실행합니다

KOSIS는 통계표마다 코드(orgId·tblId)가 달라서 처음에는 무엇을 넣어야 할지 알기 어렵다. 그래서 바로 동작하는 조합을 몇 개 넣어 두었다. 하나를 눌러 결과를 먼저 본 뒤, 아래 1~3단계에서 값이 어떻게 채워졌는지 확인하면 사용법이 한눈에 들어온다.

💡 직접 찾고 싶다면 1단계에서 검색 → 표의 행을 클릭하면 2단계 코드가 자동으로 채워진다.

1 통계표 찾기 GET /api/kosis/search 검색어를 입력하세요

KOSIS는 통계표마다 orgId(기관) + tblId(통계표) 두 코드로 식별한다. 먼저 이름으로 검색해 이 두 코드를 얻는다.

예시:
통계표기관수록 기간코드
검색어를 입력하고 「검색」을 눌러 주세요.

2 파라미터 조립 GET /api/kosis/meta 통계표를 먼저 고르세요

항목(itmId)은 위에서 고른 통계표의 메타에서 자동으로 채운다. 기간은 최근 N개 또는 시작~종료 중 하나로 지정한다.

용어 — orgId 통계를 만든 기관(101=국가데이터처) · tblId 통계표 번호 · itmId 표 안의 항목(지수·증감률 등, ALL이면 전체) · objL1 분류(지역·연령 등, ALL이면 전체) · prdSe 주기(M=월 · Q=분기 · Y=년).
전부 KOSIS가 정한 이름이라 그대로 쓴다. 값은 위 「바로 보기」를 누르거나 1단계에서 표를 고르면 자동으로 채워진다.
