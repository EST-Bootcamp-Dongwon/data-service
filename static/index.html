MOCK 국내 주식 시세 차트 ApexCharts · 캔들 + 거래량 브러시 준비 중

서버 API 없이 화면(JS)에서 만든 목업 데이터입니다. 종목코드를 난수 시드로 쓰기 때문에 새로고침해도 같은 차트가 나옵니다.

—

아래 거래량 차트를 드래그하면 위 캔들 차트의 구간이 함께 바뀝니다(브러시 연동). 상승은 빨강, 하락은 파랑으로 국내 증시 관행을 따랐습니다. 가격은 KRX 호가단위로 맞췄고 주말은 제외했지만, 공휴일은 반영하지 않은 실제와 무관한 목업입니다.

GET 서버 상태 확인 /health 확인 전

헬스 체크. 페이지를 열면 자동으로 1회 호출합니다.


    


    
    

      

        GET
        사용자 목록 조회
        /users
        
      

      
전체 사용자를 배열로 받아옵니다. 아래 검색창은 서버 필터가 아니라 받아온 결과를 화면에서 걸러내는 것입니다.


      

        
        

          
          
        

      


      


      

        

          
            
IDUsernameEmailAge

        GET
        사용자 단건 조회
        /users/{user_id}
        
      

      
없는 ID는 404, 정수가 아니면 422 가 돌아옵니다. 에러 응답도 그대로 보여줍니다.
