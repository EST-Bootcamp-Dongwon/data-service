미국 거시지표 겹쳐 보기 FRED

미국 연준(FRED)의 금리·환율·물가 데이터를 주가 거래일에 맞춰 붙인다. 발표 주기가 다르므로(금리는 일별, 물가는 월별) 직전 발표치를 다음 발표 전까지 이어 쓴다. 아직 발표되지 않은 값을 끌어오면 미래 정보가 새어 들기 때문에 항상 과거 방향으로만 채운다.

주가와의 상관계수 — 일간 변화율 기준

가격 수준끼리 비교하면 둘 다 우상향한다는 이유만으로 상관이 높게 나온다(허위 상관). 그래서 하루하루의 변화율로 바꿔서 계산한다. +1에 가까우면 같이 오르고, -1에 가까우면 반대로 움직인다는 뜻이다. 월별 지표는 값이 한 달간 그대로여서 상관계수가 0에 가깝게 나오니 참고만 한다.

API 응답 원문 — 화면이 실제로 받은 값

화면은 이 JSON을 그리기만 한다. 티커 판별·이동평균·날짜 정렬·상관계수는 전부 서버에서 끝난다. 배열이 길어 dates·prices는 앞뒤 3개만 줄여서 보여 준다. 

아직 검색하지 않았습니다.

터미널에서 같은 API 호출하기

curl 'http://127.0.0.1:8000/api/stock/005930'                        # 국내 (코스피)
curl 'http://127.0.0.1:8000/api/stock/247540'                        # 국내 (코스닥 → .KQ 자동)
curl 'http://127.0.0.1:8000/api/stock/AAPL?months=3'                 # 미국 · 3개월
curl 'http://127.0.0.1:8000/api/stock/005930?macro=DGS10,DEXKOUS'    # 거시지표 융합
curl 'http://127.0.0.1:8000/api/fred/series/DGS10'                   # FRED 단독 조회

화면도 같은 방식으로 주소에 상태를 담는다. 지금 보고 있는 화면의 주소를 그대로 복사해 넘기면 된다 — /stock?ticker=AAPL&months=3&macro=DGS10,VIXCLS
